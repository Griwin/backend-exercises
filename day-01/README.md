# Day 01 — Array filtering & sum

## 🎯 Objectif
Travailler les bases de la manipulation de tableaux en PHP, en appliquant une logique simple et lisible.
Cet exercice permet de renforcer le raisonnement algorithmique et la clarté du code.

---

## 🧩 Énoncé

À partir d’un tableau d’entiers positifs :

- créer un nouveau tableau contenant uniquement les nombres **supérieurs ou égaux à 10**
- calculer la **somme** de ces nombres filtrés

Le résultat attendu est :
- le tableau filtré
- la somme associée

$numbers = [3, 12, 7, 25, 9, 10, 18];
